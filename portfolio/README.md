# Amrita Kumari — Portfolio

Vite + React + TypeScript + Tailwind v4, shadcn-style structure (`src/components/ui`, `src/lib/utils.ts`).

- All text lives in `src/data/content.ts` — edit that to update the site.
- Case study covers and PDFs: `public/case-studies/`.
- `npm install` → `npm run dev` to run locally, `npm run build` to build.

Deploy: import this repo on vercel.com (framework auto-detected as Vite).
